RedTeamSimulator - version de développement

Lancer RedTeamSimulator.exe (Windows) ou RedTeamSimulator.x86_64 (Linux).
Le dossier engine doit rester à côté du jeu : il contient le moteur autonome.
Aucune installation de Python ou de Godot n'est nécessaire pour un paquet exporté.

Le terminal et tous les réseaux représentés appartiennent au monde simulé.
Les options prises en charge sont détaillées par help dans le terminal.
Cette version ne reproduit pas intégralement chaque outil réel.

Sauvegarde : dossier RedTeamSimulator dans les données locales de l'utilisateur.
