# Bannières orbitales des forums

Trois illustrations originales, opaques, générées puis éditées avec l'outil
imagegen intégré. Le fond de bureau orbital du jeu sert de référence de style.
Chaque scène comporte un personnage féminin adulte :

- `breachboard-orbital-v1.png` : atelier radio, tons ambre et cuivre ;
- `exployt-orbital-v1.png` : relais de communication, cockpit et lumière menthe ;
- `xsx-orbital-v1.png` : galerie d'observation, éclipse et tons olive/prune.

Ces figures appartiennent à l'illustration d'ambiance des forums. Elles ne sont
pas une photographie ni une révélation de l'identité d'un membre.

Les originaux restent intacts. Les textures importées sont limitées à 2048 pixels
sur leur plus grand côté. Godot adapte le cadrage de la bannière ; le titre et le
profil connecté restent des éléments d'interface distincts, consultables et
lisibles. Le bloc du compte est placé à gauche pour laisser les personnages
visibles dans les trois scènes.

Le manifeste `manifest.json` conserve les prompts de génération et d'édition,
les dimensions sources, les fichiers finaux et leurs empreintes SHA-256. Toutes
les ressources utilisées par le jeu sont présentes dans ce répertoire.
