# Darknet Operator — identité d'accueil

- `darknet-operator-keyart-v1.png` : illustration d'accueil générée avec imagegen.
- `darknet-operator-logo-v1.png` : logo sélectionné, version opaque sur fond anthracite,
  généré avec imagegen. L'affichage utilise une région AtlasTexture ; l'original est conservé.
- `darknet-operator-orbital-keyart-v2.png` : scène orbitale actuellement utilisée à l’accueil.
- `menu-orbital-shade-v2.svg` : dégradé anthracite pour préserver la lisibilité du menu.
- `ORBITAL_PROMPTS.md` : direction artistique et prompts des deux nouvelles illustrations.

Le nom affiché est Darknet Operator. Le nom technique Godot et les dossiers de
sauvegarde RedTeamSimulator sont conservés pour garder les profils existants.
Ces éléments constituent l'identité actuellement intégrée au menu ; ils ne sont
pas encore un ensemble de capsules et formats de publication Steam.
