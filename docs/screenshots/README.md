# Galerie du README

Ces PNG montrent l’interface du jeu dans des contextes de démonstration fictifs.
Ils sont reconstruits depuis la géométrie et les ressources de la scène Godot,
puis rendus par SVG/rsvg-convert ; ce ne sont pas des captures du rendu GPU.
Aucune sauvegarde personnelle n’est utilisée.

Le manifeste consigne les vues sources, la commande de génération, les dimensions
et les empreintes. Les ressources du jeu gardent leurs notices dans
[game/assets/CREDITS.md](../../game/assets/CREDITS.md).
